# Netflix-data-analysis
This project explores and analyzes a dataset of Netflix movies to uncover insights related to popularity trends, genre performance, user ratings, and release patterns over time. The dataset includes key attributes such as title, genre, popularity, release_date, and vote_average.
The goal of this project is to perform exploratory data analysis (EDA) on Netflix movies to answer questions like:
What genres are the most popular on Netflix?
How does the average user rating (vote_average) vary by genre?
Which Movie has lowest popularity?What is genre?
 Which Movie has Highest popularity?What is genre?
Analysis Performed:
 .Data cleaning and preprocessing
 .Visualization using libraries like Matplotlib and Seaborn
 .Genre-wise comparison of average ratings and popularity
 
Tools & Technologies
 Python
 Pandas
 Matplotlib / Seaborn
 Jupyter Notebook
